# Mohaiminul Islam Nirob — Portfolio

A personal portfolio showcasing my software projects, applied AI research, education, and leadership as a Software Engineering undergraduate at Shahjalal University of Science and Technology.

[View Portfolio](https://portfolio-swe-330.vercel.app/) · [LinkedIn](https://www.linkedin.com/in/mohaiminul-nirob-853300431/) · [Email](mailto:mohaiminulislam20000@gmail.com)

## Features

- Four sections: About Me, Learning Path, Competencies, and Contact Me.
- Project repositories, live demos, research highlights, and downloadable CV.
- Responsive layout, light and dark themes, and keyboard-accessible navigation.
- Contact form integrated with Google Forms, with direct email as an alternative.

## Built With

HTML5, CSS3, vanilla JavaScript, and Font Awesome. No framework or build step required.

## Run Locally

From the directory containing `index.html`, run:

```sh
python -m http.server 8000
```

Then open [localhost:8000](http://localhost:8000). You can also open `index.html` directly in a browser.

## Project Structure

```text
index.html   Main page and shared layout
css/         Shared and section-specific styles
js/          Section content, navigation, theme, and contact form
assets/      Photos and CV
```
